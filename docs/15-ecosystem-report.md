# 第 15 章：DSH 生态全景报告——1800+ 插件与 780 帖讨论区告诉我们的

> 本章目标：把**社区数据盘点（1804 插件）**与**本手册 780 帖讨论区观察 + 195 帖响应经验**交叉验证，画出 dsh 生态的全景图——哪里在爆发、哪里有缺口、机会在哪里。
> 数据来源：Blue-Whale-Harness 插件总表（社区维护，2026-08 抓取 1804 仓库，其中 1663 标记"真 DSH"）；讨论区观察截至 2026-08。

## TL;DR（30 秒版）

1. **生态在爆发**：1804 个插件仓库，两周内从零长出来；设计/UI 生成（348 个/94K★）和视觉（132 个/90K★）需求最旺
2. **"官方没做，社区全做"是主旋律**：桌面壳（140+）、TUI、记忆、视觉桥全是社区补位
3. **缺口明确**：金融（8 个）、数据库（14）、音频（19）、评测（37）几乎空白——但需求方在
4. **Windows 与远程是硬伤**：中文路径家族（#107 等 15+ 帖）、子进程（#717）、局域网 RPC（#755）
5. **差异化押注点**：全量 session log + 一切皆插件 + 沙箱/权限体系 → 企业/评测/合规场景

## 15.2 定性洞察（780 帖讨论区观察，交叉验证数据）

### 洞察 1：Windows 是第一大痛点（60+ 帖）

数据面：Windows 兼容是最高频话题；讨论面：**中文路径截断（#107/#151/#396/#800 等 15+ 帖同根因）**、koffi 原生崩溃（#197/#293）、端口保留区间（#589）、子进程无优雅终止（#717）、沙箱临时目录清理崩溃（#758）。

**交叉验证**：数据面"Windows 兼容差"与讨论面 60+ 帖完全互证——**这是最确定的生态短板**。

### 洞察 2："官方没做，社区全做"

数据面：桌面壳 140+、TUI 多套、记忆 77、视觉 132；讨论面：两周内社区补齐 CLI/TUI/桌面/memory/视觉（#391/#405/#386 等）。

**交叉验证**：官方（0.1.0-rc 阶段聚焦核心）与社区（补位生态位）形成健康互补——**这是生态活力的最强信号**。

### 洞察 3：安全审计异常活跃

数据面：**sandbox 分类仅 9 个插件**（安全工具稀缺）；讨论面：安全审计帖密集（#243/#250/#278/#381/#454/#774/#817 系统性审计；vm 逃逸/approval 回环/clickjacking 真实发现）+ 安全工具链（vetting/egress-guard/read-confine/check-dsh-profile）。

**交叉验证**：安全需求高（审计活跃）但安全工具少（9 个 sandbox 插件）——**供给缺口**。

### 洞察 4：序列化/边界 bug 家族集中爆发

讨论面：unknown tool ""（#725/#1405）、reasoning 序列化省略（#739/#1850）、截断 tool-call 污染（#1519）、run_code 异步回调丢弃（#1476）、损坏会话拖垮 boot（#1473/#1497）——**全是 llm-deepseek 序列化层/会话状态机的边界问题**。

**判断**：rc 期这层 bug 集中 = 官方下一轮迭代的主战场，也是社区补丁/修复分支的富矿（#1519/#725 都带测试修复）。

### 洞察 5：成本透明化是隐性刚需

数据面：内容创作 40 个/88K★；讨论面：token 消耗/缓存命中讨论密集（#735/#1052/#1234/#1374/#1520），成本工具雨后春笋（dsh-usage/usage-panel/Show Me How Much/balance-meter）。

**交叉验证**：缓存命中 97%（实测）是成本优势，但"看不见"——成本工具从"统计"到"工程"（第 14 章）是确定性方向。

## 15.4 对生态参与者的建议

### 如果你是插件开发者
1. **缺口优先**：金融/数据库/音频/评测是蓝海（竞争对手少，需求确定）
2. **安全工具稀缺**：sandbox 分类仅 9 个——安全/权限/审计类插件供给不足
3. **视觉/记忆是热点**：但竞争激烈，差异化（垂直场景/企业）比跟风更优

### 如果你在选型
1. **差异化押注点**：全量 session log + 一切皆插件 + 沙箱/权限 → **企业/评测/合规场景**（数据/讨论双验证的优势区）
2. **风险点**：Windows/远程场景当前是硬伤，团队若以 Windows 为主需评估
3. **成本优势**：缓存命中 97% × 折扣，成本透明化工具链已齐（第 14 章）

### 如果你在观望
- **生态早期红利仍在**：1804 插件但垂直领域（金融 8/数据库 14/音频 19）几乎空白，窗口期明确
- **先发者耐心**：官方 rc 迭代快，能力缝会持续出现
