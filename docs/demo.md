# 30 秒看懂 dsh（图文演示）

> 三个演示，覆盖 dsh 的三种打开方式：**Web UI**、**Headless CLI**、**插件生态**。全部为真实运行截图/输出。

## 演示一：Web UI 对话（`dsh web`）

```bash
dsh web
# 输出: dsh web: http://127.0.0.1:3080
```

浏览器打开后，新建会话，直接对话：

![dsh Web UI 对话](./assets/demo-web-chat.png)

**你看到的**：
- 左侧：会话列表 / 工作区
- 中间：对话区（输入框、模型选择 `DeepSeek V4 Flash`、推理等级 `High`）
- 右侧/底部：插件侧边栏（本图未展开，见演示三）

**真实对话**（headless 同款模型）：
> 问：你好，请用一句话介绍你自己
> 答：你好！我是 DeepSeek 驱动的 AI 编程助手，可以帮你写代码、调试问题、处理文件、搜索资料，以及完成各种开发和办公任务。

## 演示二：Headless CLI（一次性任务）

```bash
dsh --profile headless "你好，请用一句话介绍你自己"
```

真实输出：

```
你好！我是 DeepSeek 驱动的 AI 编程助手，可以帮你写代码、调试问题、
处理文件、搜索资料，以及完成各种开发和办公任务。
```

**适合**：脚本、CI、服务器自动化——打印结果后进程退出，非零退出码即失败。

## 演示三：插件生态（Git 面板）

dsh 的右侧边栏由插件提供。安装社区插件 `DSH-better-sidebar` 后（第 3 章教方法），即可获得 VSCode 风格的**源代码管理面板**：

![dsh Git 面板（better-sidebar 插件）](./assets/demo-git-panel.png)

**图中可见**：
- 分支选择器 + 刷新
- **拉取远端 / 拉取合并 / 推送** 按钮（上游状态徽标）
- 已暂存 / 未暂存区、提交框
- 右侧文件树（Explorer）

> 该面板的 push/pull/fetch 能力是社区 PR（见[第 5 章](./05-cases.md)），演示了"一切皆插件"的生态闭环。
